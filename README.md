# Fedora-niri-dotfiles.v1
A clean, minimalist and functional Niri rice built for daily use on Fedora Linux 44. This setup revolves around niri for scrollable tiling windows management, styled with custom dark-themed components.

# Included Components

- OS: Fedora Linux 44 (Workstation Edition)
- WM/Compositor: Niri
- Bar: Waybar
- App Launcher: Fuzzel
- Terminal: Alacritty
- Shell Prompt: Starship
- Fetch: Fastfetch
- Notification daemon: Mako

# Requirements & Dependencies

This setup relies heavily on Fedora's native background services like PipeWire and NetworkManager. Beyond the core tools listed above, you will only need a handfull of lightweight control apps:

- nm-connection-editor (for network management)
- overskride (for bluetooth management)
- everything in PACKAGES.md (includes the core utils and setup components)
